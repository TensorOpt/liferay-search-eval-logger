# Security Policy

## Reporting a Vulnerability

Report suspected security vulnerabilities in this plugin to
**security@tensoropt.ai**. Please do not file a public GitHub issue for a
suspected vulnerability — email the address above instead, so it is not
disclosed before anyone has had a chance to look at it.

Please include:

- The affected version or commit, and the Liferay DXP version you ran it
  against
- Steps to reproduce the issue
- What you observed and what you expected instead
- The potential impact, as you understand it

This address is for vulnerability reports only. For everything else —
questions, feature requests, bugs that are not security issues — use the
repository's normal issue tracker instead.
